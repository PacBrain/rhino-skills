# 几何验收

官方依据 R05、R07、R08、R15；方法边界如下。核对日期：2026-10-12。

## 单位与公差

文档单位、缩放、显示小数位和绝对公差不是同一设置。导入其他格式不自动保证原有文档单位/公差匹配。开始时选与模型尺度及最小特征相称的公差，之后不为拼接成功盲目增大。[R05]

网格导出公差独立于 NURBS 文档公差。[R04] STL 没有可依赖的单位，交付必须提供约定和回读尺寸。当前脚本要求 mm 源；其他单位先在副本中显式转换并验证。

## 分层检查

1. 对象数/类型、名称、设计参数和来源；开放曲面在中间阶段可能有意存在。
2. IsValid/Check、裸边、非流形边；封闭预期与任务一致。[R07、R15]
3. 法线方向和体积；镜像后的方向重新核查，不能只比包围盒。
4. 外包络尺寸、关键截面及功能位置；尺寸误差和采样范围明确记录。
5. 接缝位置误差、法线夹角、曲率与纵横走势；设计必要阶差不应被当成缺陷。
6. 派生网格有效性、封闭性、方向、非流形及可用的自交筛查。
7. STEP/STL 重读后的单位、实体/网格数量、闭合性、尺寸和必要几何差异。

## 方法能证明什么

`Check` 不完整检查曲面折回/自交；官方明确说明通过不代表所有结构都正确。[R15]

Zebra 用分析网格显示接缝走势，网格精度影响观察；连续条纹为视觉连续性证据，不单独构成全表面精确 G2 证明。[R08]

`native_ops.make_mesh` 检查派生网格，并在 API 可用时运行自交筛查；不会声称已经做完整 NURBS 全局自交证明。`brep_report` 对该项明确记录 not_run。

采样测试可能漏过未采样区域，局部最小半径不是全表面严格极值。薄壁、可拆支撑、材料收缩及人体接触需要另行分析或实测。

## 防止错误修复

不以 JoinEdge、增大公差、任意焊接或转网格掩盖坏曲面。若只是派生浮点网格产生极小接缝，必须先定位、量化，再记录有限修复阈值；源 NURBS 不应随之改变。本工具默认失败即报告，不自动修补几何。
