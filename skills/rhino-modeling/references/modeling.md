# 建模路线和失败诊断

来源 R02、R10–R14、R17，链接见 [sources.md](sources.md)。核对日期：2026-10-12。以下为工作方法，不是强制固定流程。

## 选对象类型

| 需求 | 合适路线 | 注意 |
|---|---|---|
| 精确尺寸、截面、工程交换 | 少量可解释曲线 → NURBS 曲面 → Brep | 保留尺寸基准、导线、截面、拼接关系 |
| 有机造型和迭代雕塑 | SubD | 控制拓扑和锐边，转 NURBS 后重新检查，不以外观证明尺寸精度 |
| 扫描、打印派生与轻量展示 | Mesh | 精度由网格决定，不能恢复丢失的精确设计历史 |
| 大量参数变体、依赖关系 | Grasshopper | 明确输入、范围和数据树，不把预览当已烘焙交付 |
| 重复检查、批量导出、确定性生成 | Python 3 + RhinoCommon | 检查所有返回值，记录参数与软件版本 |

SubD/mesh 的适用路线属于工程判断，具体命令能力使用当前官方帮助查询；本仓库本机几何自动测试针对 Brep/mesh，不宣称 SubD 自动化已实测。

## 曲线与曲面

- Loft：检查曲线顺序、方向、闭合缝位置与截面跨度。局部端点相触可能限制方式或引发自交。[R10]
- Sweep2：先处理两条导轨和截面的对应，匹配边界连续性可能牺牲截面贴合；必要时检查端截面保持选项。[R11]
- BlendSrf：明确位置/切向/曲率连续目标，关注角点、形状手柄和邻面结构；不为消缝盲目增加复杂度。[R12]
- 修剪和布尔：先看交线是否完整、法线和封闭性、相切接触、微小面和非流形。失败定位到实际局部，不用重复点击代替诊断。[R13]
- FilletEdge：半径受局部几何限制，检查过短边和复杂交汇；必要时回到较简单曲面/局部重构。[R14]

几何边界、渲染网格边、等参线和设计沟槽不同；不要把图片中每条黑线都建成凹槽。渐变曲面应保留设计要求的峰谷、阶差或功能转折，不能全局抹平。

## Grasshopper

Python 3 组件的 Item/List/Tree access 决定调用次数与输入形状，DataTree 不等于扁平 list。先确认数据分支、类型提示及空值，再诊断几何。脚本可能嵌入组件而不是独立文件；保存 GH 定义、输入和必要外部脚本才能复现。[R17]

不把频繁求解直接写入用户文档。明确预览、输出、Bake 与文档对象的边界。没有实际运行对应 GH 图时，把可行性判断标为文档依据。
