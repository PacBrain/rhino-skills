# 建模路线和失败诊断

以下为工程方法；各命令事实见对应官方来源，详细版本范围见 [sources.md](sources.md)。高级路线以原生软件操作或针对任务的脚本实施，不等于内置导出器已支持。

## 选对象类型

| 需求 | 路线 | 交付前重点 |
|---|---|---|
| 精确尺寸、截面、工程交换 | 基准/曲线 → NURBS 曲面 → Brep | 参数结构、面间关系、实体闭合、STEP 回读 |
| 有机外形、多轮形态调整 | 低复杂度 SubD 控制网 | 边环、锐边、极点分布、转换偏差 |
| 扫描、打印派生、轻量展示 | Mesh | 分辨率、薄壁/孔洞、法线、非流形与尺寸 |
| 参数变体、依赖关系、数据驱动 | Grasshopper | 输入范围、分支语义、稳定求解、烘焙身份 |
| 重复检查、确定性生成、批量导出 | Python 3 + RhinoCommon | 返回值、文档、版本、可追踪失败 |

先判断图中线条是几何边界、等参线、渲染网格还是实际沟槽。多块面不是缺陷；单一大曲面也不自动更光顺。尺寸、功能位置和制造接口决定分面方案。

## 曲线与 NURBS/Brep

曲线输入先查单位、开放/闭合、重复、方向、端点、扭结与自交。用尽量少的控制点表达意图；不能靠堆截面追逐噪声。曲线统一次数或结构时先保留原件，再量化偏差。`Rebuild` 的曲面偏差在指定样点计算；`RebuildCrvNonUniform` 的 RequestedTolerance 可能因控制点不足而未达到。[R22]

| 命令路线 | 适合约束 | 常见失败与处理 |
|---|---|---|
| Loft | 按顺序通过一组截面 | 对齐方向/闭合缝；检查跨度和接触端点。Rebuild/Refit 会改变输入贴合，需验收。[R10] |
| Sweep2 | 两侧导轨控制边界，截面控制形态 | 两导轨结构尽量相容；截面端点落在对应位置。复杂截面会提高输出复杂度，检查扭转和端部。[R11] |
| BlendSrf | 已有面之间的过渡 | 按边指定位置、切向或曲率目标，检查手柄和内部形状。高连续性设置仍可能产生局部下陷；预留过渡空间。[R12] |
| 修剪/布尔 | 几何相交后明确保留区域 | 看失败提示点及其附加信息；检查法线、裸边、重叠面与交线。必要时在副本上拆成求交、分割、选取、拼接。[R13] |
| FilletEdge | 有足够空间的边缘倒圆 | 检查局部最大半径、短边和交汇；按大半径到小半径尝试，适度简化共面边，必要时改用局部曲面构造。[R14] |

布尔结果为 null、空数组、多个实体或与预期体积不符时分别诊断，不能默认取返回数组第一项。每次修复后重查相邻面及关键截面，避免局部修复把问题移到另一侧。内部起伏与接缝问题采用不同诊断，见 [geometry-quality.md](geometry-quality.md)。

## SubD 与转换

SubD 适合形态探索；工程判断上，先以较稀疏控制网稳定轮廓，再增加局部边环。把 extraordinary vertices（非规则顶点）、密集边环和锐边放在可解释的位置，逐视角检查收缩、鼓包和边界。

`ToNURBS` 支持 packed/unpacked 面组织；SubD 的非规则顶点需要近似。G0 更贴近原形，G1 进一步改变局部形态，强制 G2 可能引入鼓包或凹陷。不要为获得 G2 标签自动选择最高等级。保留 SubD，比较转换后边界、特征截面、内部曲率及采样偏差，记录转换选项。[R21]

STEP 会把 SubD 导出为 polysurface，因此 STEP 导出也需要上述转换验收。[R16] 网格逐面转 NURBS 不会恢复原本的光滑设计面；精确逆向工程应由基准和截面重新约束。

## Mesh、扫描与打印衔接

先区分源网格和派生显示网格，检查离散壳体、重复/退化面、裸边、非流形、方向和尺寸。仅统一法线不等于闭合，补洞必须确认该洞不是设计特征。[R15]

`QuadRemesh` 的目标面数/边长是近似目标，导线影响拓扑，转 SubD 与插值选项可能改变尺寸；适合重组织拓扑，不能当无损简化。比较原始扫描或源几何后再接受。[R23]

`ShrinkWrap` 可从破碎几何生成包裹网格，但平滑、偏移和填洞会改变尺寸，可能关闭设计微缝。仅在任务允许重建外壳时采用，保留原件，记录参数并验收关键孔洞、间隙、厚度与偏差。[R24]

## Grasshopper

先记录 Rhino/GH 版本、插件、输入单位/范围、外部文件和期望输出数量。Python 组件：Item access 接收单项，List access 接收一个分支，Tree access 接收完整 DataTree；不要把 List 当整棵树。类型提示会转换输入，空值和未连接输入须按任务处理；Required 输入选项从 Rhino 8.14 起提供。[R17]

保留 `{path}` 与分支内索引，先打印路径、数量和类型，再诊断几何。Flatten/Graft/Simplify 会改变匹配关系，只有明确需要改变组合方式时使用；将分支数、每分支对象数和关键参数组合纳入回归。

预览几何、GH 定义文档、`scriptcontext.doc` 与 Rhino 文档对象是不同层。导出可创建组件内独立 headless 文档；不能把每次求解直接 Bake 到用户文档。[R03] Bake 应由显式输入触发，使用稳定标签/对象 ID 避免重复创建。保留 `.gh`/`.ghx`、内嵌或外部脚本、输入和插件版本；仅保存结果 3DM 无法复现参数流程。
