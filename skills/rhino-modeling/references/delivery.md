# CAD、打印与视口交付

## 格式与用途

| 格式 | 用途 | 验收重点 |
|---|---|---|
| 3DM | 原生几何、图层、视图、附加数据 | 控制曲线/参数另行保留；结果实体不自动带完整建模历史 |
| STEP | 精确 CAD 交换 | 单位、公差、对象/实体数量、闭合、方向、尺寸/体积及必要形状偏差 |
| STL | 三角网格打印交换 | 显式单位约定、有效面、闭合、方向、非流形、采样偏差 |
| 3MF | 有单位的网格与装配容器 | 通用几何 3MF 不等同有机型、材料和工艺的切片工程 |

Rhino 8 FileIO 的格式专属 options 可转成字典供读写插件使用，减少对上次 UI 设置的依赖。[R03] 记录实际选项和软件版本，不能把未指定值标为显式设置。STEP 导入/打开的单位、公差处理不同；分别记录目标文档与文件信息。[R16]

当前自动单实体导出为 STL、三角网格 JSON 和验证 JSON；不提供任意装配或多格式通用转换 CLI。合成回归额外验证 3DM/STEP 路线。正式 STEP/3MF 交付按任务编写原生脚本或使用 UI，仍需对象选择和回读验收。

## 网格误差与方向

先生成独立 Mesh，再检查并导出，分开确认 NURBS 和派生网格质量。[R04] `native_ops` 使用三角网格写标准二进制 STL，然后由 Rhino 原生回读；不修改源几何。

报告的 `requested_tolerance_mm` 是网格参数请求，`sampled_deviation` 才是实际采样结果，包含方法、样本数、面采样步长和最大采样距离。`global_error_bound: false` 明确它不是全局误差上界。最小边长、最大边长也记录在报告中；默认最大边长零表示不施加该限制。

回读比较六个边界坐标，并重查有效性、闭合、非流形、方向和可运行的自交筛查。镜像后只比较包围盒会漏掉反向壳体；网格须有可确认的外向方向。边界误差、采样偏差与实际打印分辨率不得混写成一个“精度”。

容差应由模型尺度、曲率和用途决定；示例的 0.05 mm 不是行业通用标准。对薄壁、小孔、紧弯及关键配合处增加采样，必要时进行双向几何比较；不要通过无止境加密掩盖源模型缺陷。

## 隔离生成与发布

每批先检查输入、输出名和冲突，在独立 staging 中完成所有导出及回读。只有全部通过才独占创建目标文件，不覆盖已有结果；发生可捕获异常时撤回该批已发布文件。失败的原始日志/异常留在 dispatch 结果中。

多个平铺文件不是一次原子重命名，崩溃可能留下未完成发布。因此使用新输出目录并以匹配 token 的最终 `passed` 作为完整交付标记；不能以某个 STL 存在或目录非空作为成功条件。重跑前检查原作业是否仍运行，并选择新输出目录。

交付清单至少包含源文件名/哈希、对象选择、软件版本、单位、六个边界坐标、文档公差、请求网格参数、实测方法/结果、FileIO 设置、回读与未运行项。原生文件与派生文件均保留清晰版本；下游切片可使用网格和清单，无需依赖此技能加载器。

## 真实视口证据

用 Rhino ViewCapture 或官方视口接口输出整体、关键侧视及局部。显示相机、对象版本和诊断目的；诊断图需固定斑马纹/色标/网格密度用于比较，展示图无需混入全部辅助线。

截图必须绑定实际候选，生成式示意图不能冒充 Rhino 结果。仅改显示/相机时保存并恢复状态，检查异常路径也能恢复。原生文件另存后重新打开检查内容与默认视图；CAD/软件验收不等于物理打印、装配、承重或舒适性实测。
